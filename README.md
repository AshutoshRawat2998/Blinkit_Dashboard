# Blinkit_Dashboard
Project Description Points

Project Overview: Developed an interactive Power BI dashboard analyzing Blinkit's delivery operations with $1.20M in total sales across 8,523 items, providing actionable insights into outlet performance and customer satisfaction metrics.
Key Performance Indicators: Designed and implemented KPI cards tracking critical metrics including total sales ($1.20M), average sales per transaction ($141), total inventory items (8,523), and customer ratings (3.9/5.0).

Temporal Analysis: Created a time-series line chart visualizing outlet establishment trends from 2012 to 2022, identifying peak establishment year (2018 at $205K) and overall growth patterns.

Fat Content Segmentation: Analyzed sales distribution by fat content categories (Low Fat vs Regular), revealing $776.32K in low-fat product sales and $425.3M in regular products using donut chart visualization.

Item Type Performance: Built comprehensive horizontal bar charts displaying sales performance across 12+ product categories, with Fruits and Vegetables ($0.18M) and Snack Foods ($0.18M) leading in revenue generation.

Outlet Size Analysis: Segmented outlets by size (Small, Medium, High) using donut charts, showing medium-sized outlets generating $507.90K, representing the largest share of total sales.

Location-Based Insights: Implemented tier-based location analysis (Tier 1, 2, 3) with horizontal bar charts, revealing Tier 3 locations generate the highest sales at $472.13K.

Outlet Type Comparison: Created a detailed comparison matrix analyzing four outlet types (Supermarket Type 1, 2, 3, and Grocery Store) across five dimensions: Total Sales, Number of Items, Average Sales, Average Ratings, and Item Visibility.

Interactive Filtering: Developed dynamic filter panels for Outlet Location Type, Outlet Size, and Item Type, enabling users to drill down into specific segments and customize their analysis view.

Data Visualization Techniques: Utilized multiple chart types including KPI cards, donut charts, line graphs, horizontal bar charts, and data tables to present complex datasets in an intuitive, user-friendly format.

Color Coding Strategy: Implemented consistent color schemes (yellow, green, red, blue) across visualizations to differentiate metrics and improve dashboard readability and professional appearance.

Business Intelligence Insights: Enabled data-driven decision-making by identifying that Supermarket Type1 leads in sales ($787.55K) with 5,577 items while maintaining consistent 4-star ratings across all outlet types, highlighting operational efficiency benchmarks.
